# Checkpoint 1 — RevoShop Frontend Foundations

Frontend fundamentals for RevoShop: semantic HTML/CSS, vanilla JavaScript, TypeScript, and Tailwind CSS. No framework, no bundler.

> This is a placeholder README. Full run/open instructions are added in task 10.

## Repository layout

- `html-css/` — Semantic, responsive profile page with a contact form.
- `javascript/` — Vanilla JS exercises: DOM manipulation & events, and array processing (`forEach`, `map`, `filter`, `reduce`).
- `typescript-tailwind/` — A `tsconfig`-configured TypeScript project with a Tailwind-styled, typed interactive product catalog.
- `screenshots/` — Screenshots referenced from this README.
